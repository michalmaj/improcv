# Test fixtures

## `tiny_identity.onnx`

A minimal ONNX network used by `tests/test_dnn_onnx.py` for a real (non-monkeypatched)
integration test of `improcv.load_onnx_network`/`load_onnx_network_from_bytes`, so that at
least one test exercises OpenCV's actual ONNX parser and `cv2.dnn.Net.forward()`, not only
mocks.

**Structure:** a single `Identity` operator, one input (`"input"`), one output (`"output"`),
both with the static shape `(1, 3, 4, 4)`. No weights, no trained parameters -- it does
nothing but pass its input straight through, which makes the integration tests fully
deterministic: `output == input`, exactly.

**Properties:**

- Size: 141 bytes
- SHA-256: `2f9035bf781080e0ae154cf0c1c5dcec8b92aa0f3bd36caf73cae7aadd6219c3`
- Input name: `input`
- Output name: `output`
- Operator: `Identity`
- Shape: `(1, 3, 4, 4)`
- Opset: 13
- IR version: 13
- Weights: none

**License:** this file contains no external weights and is not derived from any third-party
model -- it is a purely structural artifact (one operator, zero parameters) generated by and
for this project, and is covered by the repository's own license (see `LICENSE`), the same as
any other file here.

**No network access:** this file is committed directly; nothing in the test suite or CI
downloads it or any other model.

### Regenerating

`onnx` is not a dependency of this project (runtime, dev, or CI) -- it is needed only to
regenerate this one fixture, in a throwaway environment such as `uvx --with onnx --with numpy
python3`:

```python
import onnx
from onnx import helper, TensorProto

input_tensor = helper.make_tensor_value_info("input", TensorProto.FLOAT, [1, 3, 4, 4])
output_tensor = helper.make_tensor_value_info("output", TensorProto.FLOAT, [1, 3, 4, 4])
node = helper.make_node("Identity", inputs=["input"], outputs=["output"])
graph = helper.make_graph([node], "tiny_identity", [input_tensor], [output_tensor])
model = helper.make_model(
    graph, producer_name="improcv-test-fixture", opset_imports=[helper.make_opsetid("", 13)]
)
onnx.checker.check_model(model)
onnx.save(model, "tiny_identity.onnx")
```

After regenerating, manually verify the result still matches the properties above --
particularly size and SHA-256 (`shasum -a 256 tiny_identity.onnx`) -- before replacing the
committed file. There is no automated check that regenerates or re-verifies this file as part
of the normal test suite, lint, or CI.
